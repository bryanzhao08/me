💡  projects

things i've built.

applied research at the edge of ai and real-world systems — from hospital corridors to airfields.

01 / 02
ai fall detection
for senior care
computer vision yolov8 real-time

an ai surveillance system designed to detect fall events in elderly care facilities. uses pose estimation + anomaly detection to identify dangerous falls and alert caregivers in real time — reducing response time and improving safety for aging seniors without requiring wearable devices.

yolov8 pose opencv raspberry pi edge inference rtsp stream

02 / 02
ai aircraft taxiing,
takeoff + landing
reinforcement learning x-plane 12

trained a steady-state neural network to autonomously execute the full ground-to-air cycle — taxiing to runway, takeoff rotation, climb, stabilized cruise, descent, and autoland — inside the x-plane 12 flight simulator using the xplane sdk + custom rl reward shaping.

x-plane sdk pytorch rl / ppo steady-state nn flight dynamics
